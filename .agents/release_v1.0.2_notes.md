## 📺 YouTube TV for Android Clone (YT_TV_AC) v1.0.2

### ✨ 주요 변경 사항 (What's New)

1. **동영상 재생 속도 최대 4.0x 잠금 해제 (플레이어 코어 패치)**
   - 플레이어 번들(`tv-player-ias-tcl.js`) 내부의 재생 속도 검증 함수(`NF`) 및 가용 배속 필터(`oBf`)의 2.0x 상한선 클램프를 4.0x로 해제
   - 메뉴 또는 리모컨으로 2.0x 초과 배속(2.25x ~ 4.0x)을 선택할 때 2.0x로 강제 절삭되던 현상 완전 해결

2. **설정 $\rightarrow$ '동영상 속도' 메뉴 UI 및 가상 리스트 스크롤 잠금 해제**
   - 가상 리스트(`yt-virtual-list`)의 위치 배열 메모이제이션 고착을 우회하고 14개 전체 항목 스냅샷 생성
   - 메뉴 내에 `2.25×`, `2.5×`, `2.75×`, `3×`, `3.5×`, `4×` 항목이 완벽하게 노출되며 리모컨 방향키 및 마우스로 부드럽게 스크롤 및 선택 가능

3. **재생 속도 및 우측 상단 OSD 배지 양방향 실시간 동기화**
   - 리모컨 Ch+/Ch- 단축키 조절과 플레이어 설정 메뉴 옵션 선택 간 양방향 상태 완벽 연동
   - 실제 비디오 요소(`playbackRate`), 플레이어 내부 상태, `localStorage`, 우측 상단 OSD 배지가 모두 1:1로 일치
   - 미니멀하고 컴팩트한 OSD 배지 디자인 적용 및 Trusted Types 보안 정책 준수

4. **고배속에서 '일반(1.0x)' 복귀 시 영상 정지 버그 해결**
   - 다운시프트 시 비디오 버퍼 및 오디오 싱크 복귀 안정화
