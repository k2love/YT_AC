## 📺 YouTube TV for Android Clone (YT_TV_AC) v1.0.1

### ✨ 주요 변경 사항
1. **설정 우측 패널의 'YouTube Premium 가입' 광고 배너 완전 박멸**
   - InnerTube API 및 DOM 단계에서 Premium 안내를 원천 필터링
   - 설정 화면 진입 시 첫 번째 유효 메뉴인 **'구매 항목 및 멤버십'** 상세 화면이 기본으로 즉시 표시되도록 자동 동기화
2. **설정 하단 메뉴 분리 및 순정 디자인 적용**
   - [최신 앱 업데이트 확인]과 [앱 버전]을 독립된 2개의 메뉴 카드로 분리
   - 순정 YouTube TV 테마에 어우러지는 미니멀 다크 스타일 카드 적용
3. **버전 상향 및 인앱 업데이트 감지 연동 (v1.0.1)**
   - 앱 내부 버전을 `1.0.1` (`versionCode = 2`)로 상향
   - [최신 앱 업데이트 확인] 실행 시 최신 버전 다이얼로그 정상 표출
4. **리모컨 내비게이션 및 뒤로가기(Back) 동작 안정화**
