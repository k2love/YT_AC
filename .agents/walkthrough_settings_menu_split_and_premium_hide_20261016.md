# 작업 완료 리포트: 설정 메뉴 업데이트/버전 탭 분리 및 YouTube Premium 가입 항목 제거

## 1. 개요 및 사용자 요구사항
1. **[설정] 최하단 메뉴 분리**: `최신 앱 업데이트 확인`과 `앱 버전` 두 메뉴가 리모컨 선택 시 하나의 덩어리로 동시 선택/하이라이트되던 현상을 완전히 분리하여 각각 단독 선택되도록 조치.
2. **[설정] 최상단 불필요 메뉴 제거**: 설정 메뉴 최상단에 노출되던 `YouTube Premium 가입` 메뉴를 완전히 보이지 않게 숨김 처리.

---

## 2. 근본 원인 분석
1. **동시 선택 및 하이라이트 잔류 원인**:
   - `versionTab.cloneNode(true)`로 탭을 복제할 당시, 이미 활성화(하얗게 선택)되어 있던 `versionTab`의 포커스 클래스(`V0Tdtb`, `qzhmA`, `zylon-focus`, 내부 버튼의 `BZ345e` 등)가 복제본에 그대로 고착되었습니다.
   - 복제된 노드는 Incremental DOM(idom)의 라이프사이클 관리 밖이므로, 포커스가 이동해도 클래스가 자동 삭제되지 않아 두 항목이 항상 같이 선택된 것처럼 보였습니다.
   - 설정 메뉴의 탭들이 단순 형제 노드가 아니라 하위 컨테이너별로 분할되어 있어 리모컨 D-Pad 탐색이 가상 스크롤러에 묶이는 한계가 있었습니다.
2. **YouTube Premium 가입 노출 원인**:
   - YouTube TV 순정 UI에서 0번 인덱스 메뉴로 항상 고정 렌더링되어 있었습니다.

## 3. 적용된 수술적 정밀 수정 (Surgical Fix)
- 대상 파일: [`app/src/main/assets/h5vcc_polyfill.js`](file:///E:/AI_Projects/##%20YouTube%20TV%20for%20Android%20Clone/app/src/main/assets/h5vcc_polyfill.js)
1. **'YouTube Premium 가입' 완전 제거**:
   - `innerText`에 `/Premium|프리미엄/i` 매칭되는 탭을 탐색하여 `display: none !important`, `aria-hidden: true`, `hybridnavfocusable: false` 적용.
   - 초기 진입 시 기본 선택이 프리미엄으로 남지 않도록 첫 유효 탭(`구매 항목 및 멤버십`)으로 자동 전환.
2. **`최신 앱 업데이트 확인` 탭 상태 완전 초기화**:
   - 복제 즉시 포커스 클래스 전면 박탈 및 순수 비활성 클래스(`JqwODe`, `pAenK`, `yZD8Ze`)로 초기화.
   - `k2SetElementFocusState(tabEl, focused)` 유틸리티 함수를 통해 두 탭의 활성 상태를 상호 배타적으로 완벽 통제.
3. **전역 D-Pad 탐색 및 확인 인터셉터 (`k2SetupGlobalKeyHandler`)**:
   - `window.addEventListener('keydown', ..., true)` 캡처 단계에서:
     - `개인정보 보호 및 약관`에서 DOWN -> `최신 앱 업데이트 확인`으로 포커스 단독 이동.
     - `최신 앱 업데이트 확인`에서 DOWN -> `앱 버전`으로 포커스 단독 이동.
     - `앱 버전`에서 UP -> `최신 앱 업데이트 확인`으로 포커스 단독 복귀.
     - `최신 앱 업데이트 확인`에서 UP -> `개인정보 보호 및 약관`으로 포커스 복귀.
     - `최신 앱 업데이트 확인`에서 OK(Enter) 입력 -> `window.YT_TV_APP.checkAppUpdate()` 즉시 실행.

## 4. 실제 TV 기기(`192.168.100.121:5555`) 검증 결과

### 1) 설정 최상단 `YouTube Premium 가입` 제거 및 첫 탭 정상 표출
- **검증 사진**: `tv_screen_membership_active.png`
- **결과**: `YouTube Premium 가입`이 완전히 사라지고, 첫 메뉴가 순정 `구매 항목 및 멤버십`으로 깨끗하게 하이라이트 및 QR코드 노출.

### 2) `최신 앱 업데이트 확인` 단독 하이라이트 (완전 분리)
- **검증 사진**: `tv_screen_update_focused.png`
- **결과**: `최신 앱 업데이트 확인` 메뉴만 단독으로 하얀색 박스로 선택되고, 아래의 `앱 버전`은 일반 회색 텍스트로 비활성 상태 유지.

### 3) `앱 버전` 단독 하이라이트
- **검증 사진**: `tv_screen_version_focused.png`
- **결과**: 아래 방향키 1회 입력 시 `최신 앱 업데이트 확인`은 선택이 해제되고, `앱 버전`만 단독으로 하얗게 선택됨.

### 4) `최신 앱 업데이트 확인`에서 OK(Enter) 클릭 시 다이얼로그 팝업
- **검증 사진**: `tv_screen_dialog_enter.png`
- **결과**: 리모컨 확인 버튼 입력 시 네이티브 다이얼로그(`최신 버전 사용 중... 현재 설치된 버전(v1.0.0)이 최신 버전입니다. [확인]`)가 즉시 팝업되고, 확인 버튼으로 닫힌 뒤 정상 복귀.
